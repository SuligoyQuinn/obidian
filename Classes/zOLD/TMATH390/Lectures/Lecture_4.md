# Fundamental Principle of Counting
Theorem 4.1
	if one event can occur m ways and a second n ways, the number of ways the two events can occur together is $m*n$
	if there are $n_{1}$,$n_{2}$,...,$n_{k}$ ways to complete K tasks individually then there are $n_{1} * n_{2} *$... $*n_{k}$ ways to complete the tasks individually
- only works with discrete outcomes
- only works when number of choices at one step doesn't change based on previous steps
## Replacement
- whether or not items can be selected again after being selected once
## Order
- whether or not the order in which items are selected matters
## Factorial
- the factorial of an integer is itself multiplied by every number before it
- the number of ways to arrange n objects is n!
## Permutations
- an ordered arrangements of objects
- the number of ways to arrange r objects that were selected without replacement from n total objects when the order of the arrangement matters is given by
$$
_{n}P_{r}=\frac{n!}{(n-r)!}
$$
## Combinations
- an unordered arrangement of objects
- the number of ways to choose r objects from n total objects without replacement or regard to order is
$$
_{n}C_{r}=\frac{n!}{r!(n-r)!}
$$
