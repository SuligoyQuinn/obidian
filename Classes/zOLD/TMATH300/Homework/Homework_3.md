We will prove this using a proof by contradiction, suppose the square root of any natural number is a rational number, but not an integer. This means that $\sqrt{ n }=\frac{a}{b}$ where $a$ and $b$ are positive integers with no common factors. Squaring both sides gives us $n=\frac{a^2}{b^2}$, or $nb^2=a^2$. If $b$ is $1$ then $n=a^2\implies \sqrt{ n }=a$, making $\sqrt{ n }$ an integer, which is a contradiction. If $b\neq 1$ then $nb^2=a^2$ making $a^2$ a multiple of $b$. Because $b|a^2$ and the greatest common denominator of $a^2$ and $b$ is $1$, the only possibility is $b=1$, which is also a contradiction. q.e.d
