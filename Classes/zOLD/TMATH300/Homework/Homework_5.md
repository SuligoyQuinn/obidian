# 6.11
We will use a proof by contrapositive, suppose $X\subseteq Y$ then if if $Y$ is countable, $X$ is countable. As $Y$ is countable, that means there exists a bijection between $Y$ and $\mathbb{N}$. Because all values of $X$ exists in $Y$, the bijection works between $X$ and $\mathbb{N}$ making $X$ countably infinite.
