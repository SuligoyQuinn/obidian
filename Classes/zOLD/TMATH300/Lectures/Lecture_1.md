# Sets
- *set* is a collection of objects
	- objects are *elements* of the set
	- element can be a set itself
	- elements must be distinct
		- Non distinct elements are ignored
- $x \in A$ means x is an element in set A
- $x \notin A$ means x is not an element in set A
## Common Sets
- Natural Numbers
	- $0$ is controversial 
$$
\mathbb{N} = \{0,1,2,3,\dots\}
$$
- Integers
$$
\mathbb{Z}=\{\dots,-3,-2,-1,0,1,2,3,\dots\}
$$
- Rational Numbers
$$
\mathbb{Q}=\left\{ \frac{p}{q}\text{ where p,q}\in\mathbb{Z} \text{ and }q \neq 0 \right\}
$$
- Real Numbers
$$
\mathbb{R}
$$
## Another way of defining a set
$$
A=\{x\in A: \text{condition}(x)\}
$$
### Interval Notation
$$
B=\{x\in\mathbb{R}:0<x<1\} = (0,1)
$$
$$
B=\{x\in\mathbb{R}:0\leq x<1\} = [0,1)
$$
$$
B=\{x\in\mathbb{R}:0\leq x\leq1\} = [0,1]
$$
### Empty Set
- The *empty set* or $\varnothing$ is the set that contains no elements
- there is a difference between $\{ \varnothing \}$ and $\varnothing$
## Set Relationships
- $A \subseteq B$ means that every element of A is also in B
	- A is a *subset* of B
	- If $x \in A$ then $x\in B$
- Set A and B are *equal* if $A\subseteq B$ and $B \subseteq A$
- $A\subset B$ means A is a *proper subset* of B
	- If $x \in A$ then $x\in B$
	- $A\neq B$
