# Rules of Inference
- An *argument* is a sequence of statements that ends with a conclusion
	- Valid if conclusion of the argument must be true if all the premises are true
- A *premise* is a statement that is assumed to be true
	- usually found at beginning of argument
# Argument Form
- Modus ponens
- Premises
$$
p\implies q
$$
$$
p
$$
---
- Conclusion
$$
\therefore q
$$
