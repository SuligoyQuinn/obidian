# Counterexample
- An element $x$ for which $P(x)$ is false is a *counterexample* to the statement $\forall xP(x)$
# Existential Quantification
- The *existential quantification* of $P(x)$ is the statement:
	- "There exists an element $x$, in the domain such that $P(x).$"
- $\exists xP(x)$ is true if there is an $x$ in the domain where $P(x)$ is true, and false otherwise.
