# Propositions
- Def) Statement that makes sense to think of as true or false
	- Declarative sentence that is either true or false, *but not both*
- ex)
	- "Today is Monday"
		- Declares something
		- Truth value is false
	- "Toronto is capital of Canada"
		- Declares something
		- Truth value is false
	- "How are you Today?"
		- Does not declare something, not proposition
	- "$x+1=2$"
		- Could be true or false depends. Not proposition. Propositional function
# Logical Operators
- Negation $\neg$
	- Don't use new words in negation
- Conjunction $\land$ 
- Disjunction $\lor$
- Exclusive or $\oplus$
- Conditional statement $\implies$
- Bi-conditional statement $\iff$
# Converse, Contrapositive, Inverse
- Converse of $p\implies q$ is $q\implies p$
- Contrapositive of $p\implies q$ is $\neg q\implies \neg p$
	- equivalent to $p\implies q$
- Inverse of $p\implies q$ is $\neg p\implies \neg q$
