# Resource Management
- OS is a resource manager
	- CPU, Memory, IO
- Enables many programs to
	- share CPU
	- share underlying physical memory
	- share physical devices
- Done through virtualization
	- Presents an illusion that each program runs in isolation on its own hardware
	- Virtual form is abstract
		- CPU
			- Processes or Threads
		- Memory
			- Address Space
		- Disk
			- Files
## CPU Virtualization
- Each program gets its own virtual representation of the CPU
