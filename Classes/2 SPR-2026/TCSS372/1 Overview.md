# Computer Arithmetic
- Cannot assume all usual mathematical properties
	- Due to finiteness of representations
	- Int operations satisfy "ring" properties
		- Commutativity
		- Associativity
		- Distributivity
	- Float operations satisfy "ordering" properties
		- Monotonicity
		- Value of signs
